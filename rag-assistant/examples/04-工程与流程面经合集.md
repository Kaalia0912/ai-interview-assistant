# AI应用工程师面经合集 · 工程与流程篇

- 岗位：AI 应用工程师
- 说明：本地学习整理的常见面试题与答题要点，非平台原文搬运

## 问题与答题要点

### 1. FastAPI 的请求生命周期？鉴权和错误处理怎么做？

请求进入 → 中间件 → 路由匹配 → 依赖注入 → 业务处理 → 返回响应。鉴权简单用 X-API-Key 请求头，正式用 JWT；错误处理用 HTTPException 和全局异常处理器；前端跨域要配 CORS 中间件。

### 2. 大模型流式输出前后端怎么实现（SSE）？

后端用 StreamingResponse 逐段吐出 token；前端用 fetch + ReadableStream 逐段渲染，形成打字机效果。断线要提示重连，请求要设置合理的超时。

### 3. Docker 镜像和容器区别？Dockerfile 常用指令？

镜像是模板、容器是镜像的运行实例。Dockerfile 常用指令：FROM 基础镜像、WORKDIR 工作目录、COPY 复制文件、RUN 构建时命令、EXPOSE 暴露端口、CMD 启动命令。docker-compose 用来编排多个服务。

### 4. 服务部署后挂了，按什么顺序排查？

先看进程是否存活（docker ps），再看应用日志（docker logs），系统层看 journalctl、CPU、内存、磁盘（top / free / df），最后用 curl 测接口、复现请求看接口日志定位。

### 5. API key 怎么管理？泄露了怎么办？成本怎么控制？

key 放 .env 并加入 .gitignore，绝不提交仓库；泄露立即在控制台作废并重新生成。成本控制：相同请求加缓存、简单任务用小模型、压缩上下文、批量请求。

### 6. 大厂 AI 应用岗面试一般几轮？自我介绍怎么组织？

一般流程：简历筛选 → 笔试或机试 → 一到两轮技术面（项目深挖 + 八股 + 手撕代码）→ HR 面。自我介绍 1~2 分钟，讲"背景 + 项目 + 匹配点"，项目用 STAR（情境、任务、行动、结果）。反问环节可以问团队技术栈、业务方向、新人成长路径。

### 7. "为什么选我们公司"、职业规划和反问环节怎么准备？

为什么选我们：提前研究公司业务、产品、技术栈和岗位 JD，回答时把"公司需要什么"和"我会什么"对应起来，避免空泛夸赞。

职业规划：讲 1~3 年扎根业务、成为独当一面的工程师，3~5 年具备方向感和带人能力，体现成长性，别说不切实际的"两年当总监"。

反问环节：准备 2~3 个有信息量的问题，如团队技术栈与分工、项目当前阶段与挑战、新人成长路径与考核标准；避免一上来就问薪资福利。

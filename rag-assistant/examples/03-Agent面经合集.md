# AI应用工程师面经合集 · Agent 篇

- 岗位：AI 应用工程师 / Agent 方向
- 说明：本地学习整理的常见面试题与答题要点，非平台原文搬运

## 问题与答题要点

### 1. Agent 是什么？和普通聊天机器人的区别？

Agent = 大模型 + 工具 + 循环：模型决定调用什么工具 → 代码执行 → 结果回填 → 模型继续决策，直到完成任务。和普通聊天的区别在于能调用系统、执行操作、多步自主完成任务。

### 2. 工具调用（function calling）的完整流程？谁负责执行工具？

给模型提供工具 Schema（名称、描述、参数）→ 模型返回 tool_calls（只是"决定调哪个、传什么参数"）→ 代码里执行工具 → 结果以 role=tool 回传 → 模型生成最终答案。工具永远由代码执行，模型只做决策。

### 3. ReAct 是什么？规划方式还有哪些？

ReAct 是"思考 → 行动 → 观察"循环。进阶方式：Plan-and-Execute 先制定整体计划再逐步执行、动态调整；反思模式在失败后让模型总结原因再重试。

### 4. Agent 死循环或上下文爆炸怎么办？

设置最大迭代次数和超时；工具结果太长要截断；上下文只保留最近 N 轮；工具报错要返回给模型而不是中断；必要时加人工确认步骤。

### 5. 哪些操作必须人工审批？权限和沙盒怎么做？

删文件、转账、发邮件、下单等破坏性或不可逆操作必须人工确认。权限最小化：Agent 只能访问完成任务需要的资源；所有操作记录日志；敏感操作放沙盒环境执行。

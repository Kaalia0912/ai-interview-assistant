# AI应用工程师面经合集 · 大模型基础篇

- 岗位：AI 应用工程师 / 大模型应用岗
- 说明：本地学习整理的常见面试题与答题要点，非平台原文搬运

## 问题与答题要点

### 1. token 是什么？中文和英文的计费差异？

token 是模型处理文本的最小单元，计费和上下文窗口都按 token 计算。中文 1 个字大约 0.6~1.5 个 token，英文 1 个词约 1.3 个 token，所以中文文本整体更贵。可以用 tiktoken 或各家的 tokenizer 页面估算长度。

### 2. temperature 和 top_p 的作用？事实问答该设多少？

temperature 控制输出随机性，越高越发散，事实问答建议 0.1~0.3，创意写作 0.7~1.0。top_p 表示只从累计概率达到 p 的 token 中采样。两者都调会互相干扰，通常只调其中一个。

### 3. 对话超过上下文窗口怎么办？

至少两种方案：一是截断最旧消息只保留最近几轮；二是对历史对话做摘要压缩。进阶做法：检索只取相关片段（RAG 思路）、换更大窗口的模型、把记忆外置到数据库。

### 4. 大模型幻觉是什么？在 RAG 场景下怎么缓解？

幻觉是模型生成训练数据中不存在或不确定的内容。RAG 场景下的缓解手段：检索真实资料拼进 prompt、在 prompt 里强制"资料没有就说没有"、生成后校验引用编号、降低 temperature。

### 5. system / user / assistant / tool 四种消息角色分别做什么？

system 设定角色和规则；user 是用户输入；assistant 是模型回复，多轮对话要把历史带回去；tool 是工具执行结果，function calling 时使用。

### 6. 主流大模型有哪些？

国内 API：DeepSeek、通义千问 Qwen、Kimi、智谱 GLM、豆包；开源可本地部署：Qwen、Llama、GLM、DeepSeek 蒸馏版。大部分国内平台兼容 OpenAI 协议，改 base_url 和 key 就能切换。

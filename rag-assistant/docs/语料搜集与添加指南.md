# 语料搜集与添加指南

> 本项目语料**不随仓库公开分发**，按本指南在本地搜集、整理、入库即可。

## 零预处理：生语料直接入库

不用手动整理。把原始资料（网页复制粘贴、聊天记录、随便写的笔记、PDF、docx）直接放进 `data/mianjing/` 或网页上传，入库时系统自动做两步：

1. **规则清洗**（免费、秒级）：去掉网页导航、广告、重复行、多余空行等噪音；
2. **LLM 结构化**（默认开启）：调用 DeepSeek 把散乱的原文整理成标准模板（公司 / 岗位 / 轮次、流程概述、具体问题、经验与教训），只整理不编造，信息缺失写"未知"。

入库命令（默认自动结构化）：

```powershell
python scripts/ingest_cli.py data/mianjing
```

关闭结构化（例如大批量入库想先跑通时）：

```powershell
python scripts/ingest_cli.py --no-structure data/mianjing
```

说明：

- 已是模板格式的文档会被自动识别并跳过整理，不会重复消耗 token；
- 单篇超过 12000 字不整理、直接用原文（避免截断丢内容）；
- LLM 调用失败自动降级为清洗后的原文入库，不阻塞流程；
- 网页上传同样默认自动整理，无需任何额外操作。
- 批量入库会自动跳过目录下的 `README.md`（视为说明文件，不作为语料）；目录为空或路径不存在时命令行会给出提示。

下面第三、四节的模板与整理方式，仅在你想手动把语料整理得更精致时作为参考。

## 一、语料可以放什么

- 面经：真实面试记录（公司 / 岗位 / 轮次 / 问题）
- 题库 / 八股：开源 MIT 题库、公开笔记站的面试题整理
- 官方文档：DeepSeek API 文档、LangGraph 文档等（比二手资料更权威）
- 自己的内容：项目复盘、课程报告、论文、学习笔记（最值钱的独家语料）

## 二、来源与合规原则

| 来源 | 能否入库 | 注意 |
|------|----------|------|
| MIT 等宽松许可的 GitHub 仓库 | ✅ | 保留出处（见 data/mianjing/00-语料来源与许可.md） |
| 牛客 / 小红书 / 知乎等社区内容 | ✅ 仅本地 | 不公开分发，注明平台与链接 |
| 公开笔记站（如 kamacoder） | ✅ 仅本地 | 本地整理使用 |
| 自己的文档 | ✅ | 随意使用，欢迎公开 |

铁律：
- `data/` 目录不提交 GitHub，`.env`（API key）绝不提交；
- 有版权争议的内容只做个人学习，不二次公开。

## 三、整理模板

每篇文档建议按以下结构整理（Markdown 优先，UTF-8 编码）：

```markdown
# XX公司-AI面试-一面（2026秋招）

- 公司 / 岗位 / 轮次：XX / AI 应用工程师 / 一面
- 信息来源：牛客网（附链接）
- 流程概述：自我介绍 → 项目深挖 → 八股 → 手撕 → 反问

## 具体问题

1. 问题：完整画出 RAG 的离线 / 在线流程
   考察点：分块 → embedding → 向量库 → 检索 → 重排 → 生成

## 经验与教训

- 被追问"检索效果差怎么排查"，按分块 / embedding / 阈值 / 重排四步答
```

支持格式：md / txt / pdf / docx；扫描版 PDF 需先 OCR（如 PaddleOCR）。

## 四、添加方式

### 方式一：网页上传（日常推荐）

打开 `http://127.0.0.1:8000` → 右侧「上传语料」→ 选择文件（可多选）→ 自动入库（按文件哈希去重，重复内容自动跳过）。

### 方式二：命令行批量入库

把文件放进 `data/mianjing/`（可建子目录），然后：

```powershell
python scripts/ingest_cli.py data/mianjing
```

没有自己的语料想先体验时：`python scripts/ingest_cli.py examples`（目录里的 README.md 说明文件会自动跳过）。

### 删除文档

网页「文档管理」里点删除（会同步清理向量块与去重索引）；或手动删文件后重建（见下）。

## 五、向量库重建

### 什么时候需要重建

- 改了分块 / embedding / 检索代码之后
- 批量删除了文件之后
- 怀疑数据不一致（块数对不上、检索异常）

### 重建命令

```powershell
python scripts/ingest_cli.py --reset data/mianjing
```

`--reset` 会清空向量库与去重索引，重新读取 `data/mianjing/` 全部文档并向量化。

Docker 环境：

```bash
docker compose exec rag-assistant python scripts/ingest_cli.py --reset data/mianjing
```

### 备份建议

重建前可整体备份数据目录：

```powershell
Copy-Item -Recurse data data-backup-日期
```

关键位置：
- 向量库：`data/chroma/`
- 去重索引：`data/indexed_files.json`
- 原始语料：`data/mianjing/`

## 六、添加后质检

1. 在网页问 1~2 个与新材料相关的问题，确认能命中并带引用；
2. 定期跑 30 题评估：`python tests/run_eval.py`；
3. 观察日志 `logs/app.log`（请求耗时、token 用量）是否正常。

## 七、常见问题

- 重复上传：已按内容哈希去重，会提示「已跳过」；
- 改过的文件：内容变化会重新入库，旧块自动覆盖逻辑见重建说明；
- 块数为 0：文件为空或格式不受支持，检查内容与格式；
- 检索不到新材料：问题问法与文档措辞差异大时，尝试换关键词，或加更多相关文档。

# AI 面试经验助手 · 完整流程与使用手册

## 一、项目是什么

一个基于 RAG 的 AI 面试经验问答助手：把面经、题库、项目复盘、官方文档整理成知识库，用户提问时检索相关资料、让大模型带引用回答。

| 组件 | 技术 |
|------|------|
| 后端 | FastAPI + Uvicorn |
| 向量库 | Chroma（本地文件） |
| 向量模型 | bge-m3（硅基流动，免费） |
| 重排 | bge-reranker-v2-m3（硅基流动） |
| 生成 | DeepSeek |
| 检索 | 向量 + BM25 混合，模糊问题自动改写 |
| 部署 | Docker / 本地 Python |

## 二、完整流程总览

```
准备环境 → 获取代码 → 配置密钥 → 安装依赖 → 准备语料 → 入库
→ 本地运行 → 使用功能 → 评估与测试 → 部署上线 → 日常维护
```

## 三、分步详解

### 1. 准备环境

- Python 3.11+（本机 3.14 可用）
- 两个 API key：DeepSeek（生成答案）、硅基流动（向量 + 重排，免费额度）
- Git、现代浏览器

### 2. 获取代码

```powershell
git clone https://github.com/Kaalia0912/ai-interview-assistant.git
cd ai-interview-assistant/rag-assistant
```

### 3. 配置密钥

```powershell
copy .env.example .env
```

编辑 `.env`，填入两个 key：

```ini
DEEPSEEK_API_KEY=sk-你的DeepSeek key
EMBED_API_KEY=sk-你的硅基流动 key
EMBED_BASE_URL=https://api.siliconflow.cn/v1
EMBED_MODEL=BAAI/bge-m3
```

（重排默认复用上面的 key 和地址，无需额外配置。）

### 4. 安装依赖

```powershell
pip install -r requirements.txt
```

### 5. 准备语料

- 体验模式：直接用仓库里的 `examples/`（4 份自编合集）
- 正式模式：把原始资料（网页复制、聊天记录、PDF、docx）直接放进 `data/mianjing/`（可建子目录），
  入库时自动清洗并整理成标准模板；想手动整理得更精致时参考 `docs/语料搜集与添加指南.md`

### 6. 入库

```powershell
copy examples\*.md data\mianjing\
python scripts/ingest_cli.py data\mianjing   # 默认自动清洗 + LLM 结构化；加 --no-structure 可关闭
```

也可在网页上传（自动按内容哈希去重）。

### 7. 启动

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

或双击 `start.bat`。浏览器打开 `http://127.0.0.1:8000`（本机地址，需在浏览器地址栏手动输入）。

### 8. 使用功能

- **问答**：输入问题，流式输出，答案带引用；支持连续追问（记住最近 6 轮）
- **参考资料**：候选池 + 已引用/未引用标注
- **上传语料**：右侧面板拖入文件，自动入库
- **文档管理**：查看每份文档的块数，可删除（同步清理向量库）
- **缓存**：相同问题 1 小时内秒回
- **改写与混合检索**：模糊问题自动改写；向量 + BM25 融合检索（无需操作，自动生效）

### 9. 评估与测试

```powershell
python tests/run_eval.py    # 跑 30 道测试题，生成 tests/eval_report.md
python -m pytest tests -q   # 跑 21 项自动化测试（不联网）
```

### 10. 部署上线

本机 Docker（正常环境）：

```bash
docker compose up -d --build
```

云服务器（推荐流程）：

```bash
git clone https://github.com/Kaalia0912/ai-interview-assistant.git
cd ai-interview-assistant/rag-assistant
copy .env.example .env   # 填 key
docker compose up -d --build
```

服务器需放行 8000 端口；公网域名 + HTTPS 可后续用 nginx + certbot 配置。

### 11. 日常维护

- 加语料：放进 `data/mianjing/` 或网页上传，重复内容自动跳过
- 改代码后：`python -m pytest tests -q` + `python tests/run_eval.py`
- 重建向量库：`python scripts/ingest_cli.py --reset data/mianjing`
- 备份：定期复制 `data/` 目录（含语料、向量库、去重索引）
- 推送更新：`git add . && git commit -m "说明" && git push`

## 五、常见问题

- **启动报 8000 被占用**：关掉占用程序，或换端口 `--port 8001`
- **回答报"API key 无效"**：检查 `.env` 是否有空格、key 是否复制完整
- **检索不到相关内容**：确认语料已入库（块数 > 0），问题换关键词，或补充相关文档
- **文档管理显示块数为 0**：文件内容为空或格式不受支持，检查后重建
- **改了代码不生效**：重启服务；Docker 环境需重新 `--build`
